# SIGNAL / NOISE 随刊小课

每天最多一篇嵌入式知识短课，供 Android 应用同步。把它作为午刊制作发布的一小步。北京时间 11:15 的现有午刊任务写当日小课，14:15 的工具实验室仅在当日小课缺失时补位。沿用原任务计划。当天的分刊已发布但遗漏小课时，也可以单独补交小课。

先读当天午刊或工具实验室的原文与原作者材料，选一个能复现实验或可定量解释的问题。例如把一条“ADC 有误差”的笔记展开成一个能对照短窗和长窗的测量。优先当天同主题的小节，记录精确到锚点的刊物链接。资料不足时，可以依据厂商手册选一个独立的硬件或固件主题，省略刊物链接。旧小节作为延伸时明确写旧刊日期。任何模拟、算例、预期现象和真实采集都要分清。

每篇从现象和判断题开始。讲清从代码、信号到测量结果的因果链。给出带条件、单位和算式的数据，选一次只改变一个变量的低压实验，写出预期和两条不同结果的排障方向。硬件、软件与实验交替选题。重点写同一类问题的迁移方法。每个外链核对实页，不公开私人笔记原文、凭据或未经核实的材料。

## 更新数据

1. 取当前北京时间日期，检查 data/embedded-daily.json。当日已有记录时跳过，避免并发和重试重复发布。
2. 只追加当天一条并保留此前历史。顶层 schemaVersion 固定为 1，updatedAt 更新为 UTC ISO 8601 秒精度，例如 2026-11-19T05:45:00Z。
3. 记录的必填字段是 date、id（唯一小写短横线标识）、track（hardware、software 或 lab）、title、summary、question、mechanism（至少两段）、steps（至少两步）、expected、debug、sources（已核实的一手资料对象数组，每项包含 title 和 URL 字段 url）。可选 calculation 是一条可独立阅读的算式。对得上的杂志小节写入 magazine，其 title 和 url 为刊名短标题和本刊 HTTPS 地址。现有离线模型仅识别 demo=adc 或 demo=pwm，模型参数须与示例一致。
4. 运行 python scripts/validate_embedded_daily.py 校验日课，再按原刊流程构建和提交。同一轮通过 Pages 发布到 data/embedded-daily.json，原始仓库的同路径是手机备用读取地址。推送仍需正常等待 Pages 对应提交完成。校验或写作遇阻时，保留最近有效数据并照常交付杂志。
5. 确认线上 feed 有当天日期且对应刊物锚点可访问。记录实际结果，区别已写入、已部署和定时运行的结果。手机打开或点击同步会读取新内容，已读内容可离线访问。
